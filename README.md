# YusufBeratZengin

I build small, well-tested developer tools for AI agents, prompts, i18n, Turkish-language text processing, and video automation. I also contribute translations and fixes to open-source projects.

## Featured

- [agent-guardrails](https://github.com/YusufBeratZengin/agent-guardrails) — Auditable, local safety hooks for AI coding agents.
- [prompt-lint](https://github.com/YusufBeratZengin/prompt-lint) — Lint LLM prompts and agent instruction files such as CLAUDE.md and AGENTS.md.
- [remotion-shorts-kit](https://github.com/YusufBeratZengin/remotion-shorts-kit) — A TypeScript Remotion starter kit for vertical explainer videos.
- [subtitle-tools](https://github.com/YusufBeratZengin/subtitle-tools) — Convert, fix, and lint SRT, WebVTT, and ASS subtitles with zero runtime dependencies.
- [tr-pii](https://github.com/YusufBeratZengin/tr-pii) — Detect and mask personal data in Turkish text offline.
- [cron-explain](https://github.com/YusufBeratZengin/cron-explain) — Explain cron expressions in English and Turkish, with next run times and time zone support.
